# Foodwell

Foodwell is a RESTful Web service for an online grocery store. It allows customers to browse products, manage a shopping cart, place orders, and track delivery status. Store staff can manage inventory and update order/delivery status, while administrators manage the product catalog, categories, and user accounts.

The service exposes resources for products, categories, customers, carts, orders, and delivery slots, backed by a relational database. Access is controlled through authentication and role-based authorization.
